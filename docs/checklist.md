# Release Readiness Audit Checklist

Starter checklist for the release-readiness audit. Each section maps to one of the tracked workstreams.

## Collect stakeholder requirements

- [ ] Identify all internal and external stakeholders
- [ ] Schedule requirement-gathering sessions
- [ ] Document functional and non-functional requirements
- [ ] Confirm sign-off criteria with each stakeholder group

## Draft the audit checklist

- [ ] Define audit scope and objectives
- [ ] List all audit items per workstream
- [ ] Assign owners to each checklist item
- [ ] Agree on pass/fail criteria
- [ ] Review checklist with the team

## Schedule the review meeting

- [ ] Find a time slot that works for all stakeholders
- [ ] Send calendar invites
- [ ] Prepare the agenda
- [ ] Share the draft checklist in advance
- [ ] Record decisions and action items
